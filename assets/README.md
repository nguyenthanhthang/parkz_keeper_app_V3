# Assets Folder

Thư mục này chứa các assets cho ứng dụng (images, icons, fonts).

## Các file cần thiết (tùy chọn):

- `icon.png` - App icon (1024x1024px)
- `splash.png` - Splash screen image (1242x2436px)
- `adaptive-icon.png` - Android adaptive icon (1024x1024px)
- `favicon.png` - Web favicon (48x48px)

## Hiện tại:

App đang sử dụng màu nền đơn giản cho splash screen và adaptive icon.
Bạn có thể thêm các file assets vào thư mục này sau.
